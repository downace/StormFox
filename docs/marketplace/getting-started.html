1. Install Mago and make sure it runs on your machine.
  2. Open Settings | PHP | Quality Tools | Mago and set Mago executable to the path of the binary.

  • Formatting: enable Use Mago formatter, then use Reformat code (Ctrl+Alt+L).
  • Formatting on save: also enable Reformat code in Settings | Tools | Actions on Save.
  • Linting: in Settings | Editor | Inspections enable PHP | Quality tools | Mago validation.
